# Synthetic evidence review: balanced 40



**All added answers below are deliberately fabricated experimental stimuli. They are not verified facts or advice.**



Each single-evidence condition uses the listed source QA item. The full-plus-contradiction condition retains all original QA items and appends the contradictory answer with the same question and a new ordinary QA ID. No synthetic provenance or review note is shown to the model.



These drafts were authored by the assistant from the supplied evidence. `review_status: draft` records that no human semantic review has been performed. Structural checks cannot validate contradiction quality. You can edit the JSON before running; its hash is saved in run metadata. No separate approval step is enforced by the runner.



Some NEI records contain only limited background facts. Their contradictions concern that background, not the unresolved claim itself. One-item source records make single and full evidence identical; these are retained and should be flagged during analysis. Appending an item also changes length and position, so the experiment does not isolate contradiction from those effects.
